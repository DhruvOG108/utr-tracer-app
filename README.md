# 📊 UTR Transaction Tracer

A Python-based web application built with Streamlit. This tool uses Depth-First Search (DFS) graph traversal to automatically trace financial transaction layers from raw `.xlsx` logs and formats them into a clean, hierarchical report.

## Tech Stack
* Python 3.10
* Streamlit
* Pandas & Openpyxl

## How to Run Locally
1. Clone the repository.
2. Install requirements: `pip install -r requirements.txt`
3. Run the app: `streamlit run app.py`
